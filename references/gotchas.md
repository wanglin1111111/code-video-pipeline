# 坑位与脏活清单

## 画面类（人眼验收必查）

| 坑 | 表现 | 对策 |
|---|---|---|
| 平移露黑边 | 镜头平移/缩放时画面边缘露出背景黑边 | 元素安全边距 > 最大位移量；验收时逐镜看四角 |
| 星芒盖屏 | 装饰粒子/星芒飘到字幕区或主体上 | 装饰层 z-index 低于字幕层 + 字幕区禁飞区；硬约束写进元指令 |
| 时间轴重叠 | 同时间段两组画面事件或音频事件撞车 | 分镜表生成时做重叠检查；静默版验收逐段过 |
| 随机不可复现 | 重跑两次结果不一样 | 随机种子写死进代码；确定性是这条路线的卖点，丢了就白做 |
| 节奏卡不上 | 动效节奏和 BGM/配音对不上 | 先定时间轴再动画效，动画效迁就时间轴，不反过来 |

## 音频类

| 坑 | 表现 | 对策 |
|---|---|---|
| TTS key 余额不足 | 配音中途断 | 开工前查余额；余额管理是人的活，不指望 Agent 盯 |
| 人声盖 BGM 失控 | 配音出现时 BGM 不闪避 | 侧链压缩参数验收试听；闪避深度不够就加大 |
| 程序化音色单薄 | DSP 合成乐器/音效听感塑料 | 关键乐器可混入真实采样；或降低该音色在 BGM 中的占比 |
| 音画不同步 | 字幕/配音与画面对不齐 | 时间轴为单一事实源：画面、字幕、音频都从分镜表时间轴派生 |

## 工程类

| 坑 | 表现 | 对策 |
|---|---|---|
| ffmpeg 兼容 | 编码参数/容器在某些播放器不兼容 | 用经过验证的编码参数模板；交付前在目标播放器实测一次 |
| 单文件 HTML 过大 | Three.js + 资源内联后文件巨大 | 纹理外链或压缩；分镜复杂度控制 |
| 长程任务中断 | 2 小时级任务跑一半失败 | 每阶段产物落盘（分镜表/截图/脚本），断点从阶段产物续跑，不从头 |
| 额度不够烧 | 1700 万 Token 级消耗撞额度墙 | 重活排额度重置窗口后；小改动用 low/medium 档重跑而非全量重生成 |

## 工作流类

| 坑 | 表现 | 对策 |
|---|---|---|
| 一次梭哈 | 一次性要全套，返工成本翻倍 | 分阶段：静默版验收过再上音频 |
| 只收 MP4 | 下次改文案从头再来 | 交付四件套强制：index.html/SRT/截图/脚本 |
| 每次从零写提示词 | 元指令没沉淀 | 第 2 个片子起必须复用元指令 md，坑写进硬约束节 |
| 代码路线硬啃写实 | 拿短板撞长板 | 分流判据前置：真实感/人物/物理走视频模型 |
| 相信"模型说没问题" | 验收走过场 | 逐镜截图人眼过；模型自述不是验收依据 |
